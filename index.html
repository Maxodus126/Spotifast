Make Spotify truly yours.

Command-line tool to customize the official Spotify client — colors, CSS, extensions and custom apps.

Open Source LGPL-2.1 Windows · macOS · Linux
Download How to install

Features

The same engine as Spicetify, rebranded.

Custom colors

Change every color across the Spotify UI.

CSS injection

Full control over styling with your own CSS.

Extensions

Add functionality, control the player, remap keys.

Custom apps

Add new pages like lyrics, new releases and Reddit.

Install

Spotify must already be installed. Spotifast is a CLI tool — there is no setup.exe.

Windows (PowerShell)

# install
iwr -useb https://raw.githubusercontent.com/Maxodus126/Spotifast/main/install.ps1 | iex

# back up Spotify, then apply
spotifast backup
spotifast apply

Linux / macOS

# install
curl -fsSL https://raw.githubusercontent.com/Maxodus126/Spotifast/main/install.sh | sh

spotifast backup
spotifast apply
Before you install: Spotifast patches Spotify's files, violates Spotify's Terms of Service (a ban is possible), and does not remove ads. Ad-free listening requires Spotify Premium. Use at your own risk.
